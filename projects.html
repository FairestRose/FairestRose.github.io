Secure IoT Medication Alert System

An end-to-end IoT application designed for reliable medication adherence. Built on a Raspberry Pi Zero, it features a custom Linux Kernel Module for hardware isolation, a Python-based alert daemon, and a local Flask dashboard.

The system securely syncs configurations and telemetry with an AWS serverless backend (API Gateway, Lambda, DynamoDB) and utilizes mutual-TLS MQTT via AWS IoT Core for real-time monitoring and remote commands.
